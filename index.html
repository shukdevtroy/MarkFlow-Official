What makes it different

Not just a converter. A typesetter.

Most tools hand you raw HTML and wish you luck. MarkFlow ships every export fully styled, so the page you preview is the page you publish.

Batch mode

Twenty files. One click.

Drop a folder of .md, .markdown or .txt files. MarkFlow converts three at a time, shows live progress per file, and bundles everything into a single zip. Oversized files fail gracefully without stopping the rest, and changing the theme re-converts everything that's done.

Run it yourself

Host it your way.

MarkFlow is a FastAPI backend and a React frontend. Start both in two terminals, then open this site at localhost:5173 and the app at localhost:5173/app/.

Backend
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
Frontend
cd frontend
cp .env.example .env
npm install
npm run dev
MAX_UPLOAD_MBLargest file the API accepts, in megabytes. Defaults to 1.
ALLOWED_ORIGINSComma-separated list of frontend URLs allowed to call the API.
VITE_API_URLWhere the frontend finds the API. Set it before you build.

To deploy, the repo includes a render.yaml that sets up both services on Render: the API as a web service and the frontend as a static site. Right now the github repository is not public. The app is public for all to use.

FAQ

Questions, answered.

Is MarkFlow free?

Yes. There is no sign-up and nothing to install. Open the app and start writing.

Where does my Markdown go?

Your text is sent to the MarkFlow API, converted in memory and sent straight back. The server does not store documents. Your draft, export theme and pane layout are saved only in your own browser.

What are the file limits?

Batch mode takes up to 20 files at a time. Files must be .md, .markdown or .txt, saved as UTF-8, and up to 1 MB each by default. If you host MarkFlow yourself, set MAX_UPLOAD_MB to change the limit.

Why was the first conversion slow?

The hosted server sleeps when nobody has used it for a while. The first request can take up to a minute to wake it. After that, conversions are fast.

Which Markdown features work?

Headings, lists, tables, links, blockquotes, fenced code blocks with syntax highlighting, and an automatic table of contents. Conversion uses Python-Markdown and Pygments.

How do I get a PDF?

Select PDF above the preview, then choose Save as PDF in the print dialog. Print styles switch to black on white and wrap long code lines so nothing is cut off.

Is it safe to preview untrusted files?

The preview runs in a sandboxed frame with scripts turned off, so nothing in a document can run while you look at it.
