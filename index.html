What makes it different

Not just a converter. A typesetter.

Most tools hand you raw HTML and wish you luck. MarkFlow ships every export fully styled, so the page you preview is the page you publish.

◧

Live split view

Type on the left, watch the page rebuild on the right ~450 ms after your last keystroke. Stale requests are cancelled and your scroll position survives every update.

Aa

Four export themes

Minimal, Editorial (with a magazine drop cap), GitHub and Dark. Switch instantly, and the exported file carries the style with it.

☰

Auto outline

{ }

Syntax highlighting

Fenced code blocks are highlighted by Pygments with a palette that matches each theme, light or dark.

⎙

Print-perfect PDF

Dedicated print styles force clean black-on-white, avoid orphaned headings and wrap long code instead of cutting it off.

⛨

Safe by design

The preview runs in a sandboxed iframe with no script permission, so nothing inside a document can ever execute.

G

Batch mode

Twenty files. One click.

Drop a folder of .md, .markdown or .txt files. MarkFlow converts three at a time with live progress per file and an overall bar, then bundles everything into a single zip. Oversized files fail gracefully, failed ones can be retried, and changing the theme re-converts everything that's done.

Run it yourself

Host it your way.

MarkFlow is a FastAPI backend and a React frontend. Start both in two terminals and open the app at localhost:5173. Without a DATABASE_URL the backend falls back to a local SQLite file, and without a Google client ID sign-in is simply hidden.

Backend
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
Frontend
cd frontend
cp .env.example .env
npm install
npm run dev
MAX_UPLOAD_MBLargest file the API accepts, in megabytes. Defaults to 1.
ALLOWED_ORIGINSComma-separated list of frontend URLs allowed to call the API.
VITE_API_URLWhere the frontend finds the API. Set it before you build.
GOOGLE_CLIENT_IDOAuth web client ID for the API. The frontend needs the same value as VITE_GOOGLE_CLIENT_ID.
DATABASE_URLPostgres connection string, for example from Neon. Falls back to local SQLite.
SECRET_KEYSigns login sessions. Render can generate one for you. Optional: SESSION_DAYS, MAX_DOCS_PER_USER.

To deploy, the repo includes a render.yaml that sets up both services on Render: the API as a web service and the frontend as a static site. Right now the github repository is not public. The app is public for all to use.

FAQ

Questions, answered.

Is MarkFlow free?

Yes. Nothing to install, and an account is optional. Open the app and start writing, or sign in with Google if you want to save files.

Do I need an account?

No. Choose Try as Guest and you can convert, preview, download and batch-export right away. An account only adds saved files that you can reopen later.

Where does my Markdown go?

Converting is done in memory and the result is sent straight back, nothing is stored. Only if you are signed in and press Save is that file stored in the database under your account, and only you can see or delete it. Your draft, export theme and pane layout are kept in your own browser.

What are the file limits?

Batch mode takes up to 20 files at a time. Files must be .md, .markdown or .txt, saved as UTF-8, and up to 1 MB each by default. Each account can keep up to 100 saved files. If you host MarkFlow yourself, set MAX_UPLOAD_MB and MAX_DOCS_PER_USER to change these.

Why was the first conversion slow?

The hosted server sleeps when nobody has used it for a while. MarkFlow wakes it as soon as the app opens and keeps retrying for about a minute, so the first request can take that long. After that, conversions are fast.

How long does a sign-in last?

Seven days by default. When a session expires, the sign-in popup reappears. Signing out manually also clears the draft from your device.

Which Markdown features work?

Headings, lists, tables, links, blockquotes, fenced code blocks with syntax highlighting, and an automatic table of contents. Conversion uses Python-Markdown and Pygments.

How do I get a PDF?

Select PDF above the preview, then choose Save as PDF in the print dialog. Print styles switch to black on white and wrap long code lines so nothing is cut off.

Is it safe to preview untrusted files?

The preview runs in a sandboxed frame with scripts turned off, so nothing in a document can run while you look at it.
